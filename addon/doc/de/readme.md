# xTrack

### **Effizientes Toolkit für Multimedia-Konvertierung & Bearbeitung**

xTrack ist ein vielseitiges NVDA-Add-on, das die Arbeit mit Multimedia-Dateien direkt im Windows-Explorer vereinfacht. Es bietet einen optimierten Workflow zum Konvertieren, Zusammenfügen und Bearbeiten von Audio, Video und Bildern, ohne dass komplexe externe Software erforderlich ist.

**Autor:** chai chaimee & malee yamazaki  
**url:** https://github.com/chaichaimee/xTrack

---

## Was ist neu

• **Video-Info:** Schnelles Abrufen technischer Metadaten von Videodateien.  
• **Bild-Info:** Schnelles Abrufen technischer Metadaten von Bilddateien.  
• **Bildgröße ändern:** Neue Crop-Funktion für präzise Bildausschnitte hinzugefügt.  
• **Audio teilen:** Neues Tool zum Aufteilen von Audiodateien in festgelegte Intervalle.  

---

## Tastenkombinationen

* **NVDA+X:** Öffnet das Kontextmenü mit folgenden Optionen:
  * Audio konvertieren
  * Video konvertieren
  * MP3 in MP4 umwandeln
  * MP3 zusammenfügen
  * Audio/Video zuschneiden
  * Audio teilen
  * Bildgröße ändern
  * Bild-Informationen
  * Video-Informationen
  * Aufnahme-Einstellungen

* **STRG+Umschalt+Leertaste:** Aufnahme starten (erneutes Drücken pausiert die Aufnahme)
* **STRG+Windows+Leertaste:** Aufnahme beenden

---

## Funktionen & Bedienung

### • Audio konvertieren
**Erleben Sie nahtlose Audio-Extraktion und Konvertierung mit professionellen Ergebnissen.** Wählen Sie eine oder mehrere Dateien im Explorer aus, drücken Sie **NVDA+X** und wählen Sie **Audio konvertieren**. Das Konfigurationsfenster berechnet automatisch die Dauer. Sie können die Qualität anpassen, bevor Sie starten. Das System nutzt eine Warteschlange, um Dateien nacheinander zu verarbeiten, was CPU und RAM schont.

### • MP3 in MP4 umwandeln
**Verwandeln Sie Ihre Audiotracks ganz einfach in teilbare Video-Inhalte.** Wählen Sie eine MP3-Datei aus, drücken Sie **NVDA+X** und wählen Sie **MP3 in MP4 umwandeln**. Sie können Bilder für eine Slideshow hinzufügen, die Anzeigedauer festlegen oder einfach eine Hintergrundfarbe wählen, um das Video zu generieren.

### • Video konvertieren
**Hochwertige Video-Transkodierung für maximale Kompatibilität.** Markieren Sie das Video, drücken Sie **NVDA+X** und wählen Sie **Video konvertieren**. Im Einstellungsfenster können Sie das Zielformat und die gewünschte Qualität festlegen.

### • MP3 zusammenfügen
**Kombinieren Sie Ihre Audioprojekte mit fließenden Übergängen.** Wählen Sie mehrere Dateien oder einen Ordner aus, drücken Sie **NVDA+X** und wählen Sie **MP3 zusammenfügen**. Sie können die Reihenfolge ändern und zwischen **Normalem Zusammenfügen** oder **Cross-fade** (Überblendung) wählen.

### • Aufnahme
**Halten Sie wichtige Momente mit dem barrierefreien Hintergrund-Recorder fest.** Konfigurieren Sie zuerst das Format in den **Aufnahme-Einstellungen**. Nutzen Sie dann **STRG+Umschalt+Leertaste** zum Starten/Pausieren und **STRG+Windows+Leertaste** zum automatischen Speichern.

### • Audio teilen
**Präzises Aufteilen langer Aufnahmen in organisierte Segmente.** Wählen Sie die Datei aus, drücken Sie **NVDA+X** und wählen Sie **Audio teilen**. Legen Sie im Fenster die Anzahl der Schnittpunkte und die genauen Endzeiten für jedes Segment fest.

### • Audio/Video zuschneiden
**Entfernen Sie unerwünschte Teile schnell und unkompliziert.** Wählen Sie die Datei aus, drücken Sie **NVDA+X** und wählen Sie **Audio/Video zuschneiden**. Das Tool berechnet die Länge automatisch; geben Sie einfach Start- und Endpunkt an. Nutzen Sie die **Vorschau**, um den Startpunkt zu prüfen.

### • Bildgröße ändern
**Perfektionieren Sie Ihre Bilder mit integrierten Werkzeugen zum Skalieren und Zuschneiden.** Wählen Sie Bilder aus, drücken Sie **NVDA+X** und wählen Sie **Bildgröße ändern**. Ändern Sie Dimensionen, schneiden Sie Bilder zu oder konvertieren Sie Formate in einem Rutsch.

### • Bild-Informationen
**Sofortiger Zugriff auf wichtige Bild-Metadaten.** Wählen Sie ein Bild aus und nutzen Sie **Image Info** im Menü. NVDA sagt Ihnen sofort die Abmessungen und die Auflösung an.
