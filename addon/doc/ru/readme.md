# xTrack

### **Эффективный набор инструментов для работы с мультимедиа**

xTrack — это универсальное дополнение для NVDA, упрощающее работу с медиафайлами прямо в проводнике. Конвертируйте, объединяйте и редактируйте аудио, видео и изображения без использования сложных сторонних программ.

**Автор:** chai chaimee & malee yamazaki  
**url:** https://github.com/chaichaimee/xTrack

---

## Что нового

• **Инфо о видео:** Быстрое получение технических метаданных видеофайлов.  
• **Инфо об изображении:** Просмотр спецификаций графических файлов.  
• **Изменение размера:** Добавлена функция обрезки (Crop) для точного кадрирования.  
• **Разделение аудио:** Инструмент для деления аудиофайлов на сегменты.  

---

## Горячие клавиши

* **NVDA+X:** Открывает контекстное меню со следующими опциями:
  * Конвертировать аудио
  * Конвертировать видео
  * Конвертировать MP3 в MP4
  * Объединить MP3
  * Обрезать аудио/видео
  * Разделить аудио
  * Изменить размер изображения
  * Инфо об изображении
  * Инфо о видео
  * Настройки записи

* **CTRL+Shift+Пробел:** Запись (повторное нажатие — пауза)
* **CTRL+Windows+Пробел:** Остановить запись

## Функции и использование

### • Конвертация аудио
**Профессиональное извлечение и конвертация аудио без лишних усилий.** Выберите файлы в проводнике, нажмите **NVDA+X** и выберите **Конвертировать аудио**. Система автоматически рассчитает длительность. Вы можете настроить качество перед запуском. Очередь обработки гарантирует стабильность работы системы.

### • Конвертация MP3 в MP4
**Легко превращайте аудиозаписи в видеоконтент для соцсетей.** Выберите MP3, нажмите **NVDA+X**. Вы можете добавить изображения для слайд-шоу, настроить их длительность или использовать сплошной цвет фона.

### • Конвертация видео
**Надежное перекодирование видео с сохранением высокого качества.** Выберите видеофайл, нажмите **NVDA+X**. В настройках укажите желаемый формат и качество вывода.

### • Объединение MP3
**Склеивайте аудиофайлы с плавными переходами.** Выберите файлы или папку, нажмите **NVDA+X**. Доступно изменение порядка треков и выбор между **Обычным слиянием** или **Кроссфейдом (плавный переход)**.

### • Запись
**Записывайте важные моменты с помощью удобного фонового рекордера.** Настройте формат в **Настройках записи**. Используйте **CTRL+Shift+Пробел** для управления записью из любого окна Windows.

### • Разделение аудио
**Точное деление длинных записей на организованные фрагменты.** Выберите файл, нажмите **NVDA+X** и **Разделить аудио**. Укажите количество частей и точное время окончания каждого сегмента.

### • Обрезка аудио/видео
**Быстро удаляйте лишние части, оставляя только самое важное.** Выберите файл, нажмите **NVDA+X** и укажите точки начала и конца. Используйте **Предпрослушивание** для проверки перед обработкой.

### • Изменение保留 размера изображения
**Доведите визуал до совершенства с инструментами масштабирования и обрезки.** Выберите изображения, нажмите **NVDA+X**. Меняйте разрешение и конвертируйте форматы за один шаг.

### • Инфо об изображении
**Мгновенный доступ к метаданным изображения.** Выберите файл и воспользуйтесь меню **NVDA+X**. NVDA озвучит разрешение и размеры картинки.
